# Músicas de Mozart (e no estilo de Mozart) liberadas para o canal

Levantamento feito em 04/10/2026 a partir da API do Wikimedia Commons, que hospeda
cópias das gravações do Musopen com a licença de cada arquivo.
Foco: movimentos lentos e calmos (Andante, Adagio, Larghetto, Romanze),
bons para estudar, relaxar e dormir.

> **Regra de ouro:** a composição de Mozart é domínio público, mas a **gravação** precisa ser
> livre também. Use só arquivos marcados como **Public domain** ou **CC0**, e guarde o link
> da página de cada arquivo como prova para contestar reivindicações do Content ID.
